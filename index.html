Hermes Personal Agent

A self-hosted personal automation tool.

What this is

Hermes Personal Agent is a privately operated, self-hosted software agent that a single individual runs on their own machine. It is used to read, organise and act on that one person's own data — email, files, calendar, documents and spreadsheets — at their explicit request, in the same way a person might use a desktop mail client or a file manager.

Who uses it

Exactly one person: the operator who installed it. There is no sign-up, no user base, no accounts, and no service offered to the public. The software is not distributed and is not available for others to use.

How it accesses data

The agent connects to Google services through the standard OAuth 2.0 authorisation flow. The operator grants access themselves, on their own account, and can revoke it at any time from their Google Account permissions page. Access is limited to the scopes the operator approved.

Data handling

All data retrieved by the agent stays on the operator's own hardware. Nothing is transmitted to any third-party service operated by this project, because no such service exists. See the Privacy Policy for specifics.

Contact

This is a personal project. Questions about it should be directed to the operator through the support address configured on its OAuth consent screen.
