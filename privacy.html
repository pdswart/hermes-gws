Privacy Policy

Hermes Personal Agent — last updated 6 November 2026

Scope

This policy covers Hermes Personal Agent ("the agent"), a self-hosted piece of software operated by a single individual on hardware they control. The agent is not a commercial service and has no users other than its operator.

What data is accessed

Only with the operator's explicit OAuth consent, and only within the scopes granted, the agent may access:

  • Gmail messages (read, send, modify)
  • Google Drive files
  • Google Calendar events
  • Google Contacts (read-only)
  • Google Sheets and Google Docs

All of this data belongs to the operator's own Google account.

How data is stored

Data retrieved by the agent is processed and stored on the operator's own machine. OAuth access and refresh tokens are stored locally in a file readable only by the operator's system account. Tokens are never embedded in this website or in any public repository.

How data is shared

The agent does not sell, rent, publish, or otherwise disclose the operator's data to any third party. There is no analytics, advertising, tracking, or telemetry in the agent, and no central server operated by this project to which data could be sent.

Third-party processing

When the operator asks the agent to perform a task, the agent may send the minimum context required to a large-language-model provider for the sole purpose of producing that response. This happens only on the operator's instruction and uses the provider the operator has configured.

Data retention and deletion

Retained data lives on the operator's hardware and is deleted at their discretion. Revoking the agent's access from the Google Account permissions page immediately invalidates its tokens.

Revoking access

The operator can revoke access at any time at myaccount.google.com/permissions. Revocation takes effect immediately and requires re-consent before the agent can access Google data again.

Children

The agent is not directed at children and is not used by anyone other than its operator.

Changes

Any change to this policy will be reflected on this page with an updated date.
